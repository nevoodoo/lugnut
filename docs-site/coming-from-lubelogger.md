# Coming from LubeLogger

!!! note "Planned, arriving in a later release"
    The importer is not available yet. This page describes what is planned.

Importing from LubeLogger is a core goal for Lugnut. The plan is to import a whole instance, either from its backup zip or from its API, with a preview you can correct before anything is saved.

What is planned:

- Vehicles, service, repair and upgrade records, fuel, odometer readings, taxes, reminders, notes and to-do items.
- Attachments, purchase price and custom fields.
- Odometer readings stored as 0 are imported as no reading.
- Running the import again adds only new records and never changes existing ones.
- Supplies, equipment and inspections are skipped and listed in an import report.

Follow progress on the [roadmap](roadmap.md).
